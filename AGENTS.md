# Project layout

This is a single-file web app. Keep these files at the top level:

- `index.html` - the complete web app and the GitHub Pages entry point
- `AGENTS.md` - project instructions and layout
- `spec.md` - project requirements and design specification
- `prompts.md` - a log of requests, changes, and results

Use numbered folders for supporting work:

- `00_planning/` - notes, sketches, and planning documents
- `01_data/` - source data and data files
- `02_validation/` - hand calculations, test cases, and validation evidence
- `03_output/` - screenshots and exported results

Save new files in the folder that matches their purpose. Do not add extra top-level folders. After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
